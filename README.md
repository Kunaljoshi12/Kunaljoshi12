I'm a QA Engineer with **1.5+ years of experience** testing web and mobile applications in the Capital Markets domain.

My work focuses on automation, backend data validation, reliable releases, and using AI tools to improve testing workflows.

```text
FOCUS       → Quality Engineering & Test Automation
```

I want to contribute across the SDLC—not just identify defects, but help build, validate, and improve software systems.
